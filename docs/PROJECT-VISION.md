# PROJECT-VISION.md — AI 시장지능 전략 연구소

> 마지막 갱신: 2026-06-23  
> 이 문서는 프로젝트의 방향성과 철학을 정의한다.  
> 기능 구현이 이 철학과 충돌하면, 구현을 바꾸거나 사용자에게 확인을 받는다.

---

## 1. 이 프로젝트는 무엇인가

**AI 기반 시장지능 전략 연구소 (AI Market Intelligence Trading Lab)**

단순히 매수·매도 주문을 자동화하는 봇이 아니다.  
이 시스템의 목적은 **"AI가 시장을 지속적으로 학습하고, 검증된 전략만 실전에 배치하는 연구 인프라"** 를 만드는 것이다.

---

## 2. 왜 자동매매 봇이 아닌가

자동매매 봇의 한계:
- 전략을 사람이 직접 만들고 파라미터를 직접 튜닝해야 한다.
- 시장이 변하면 전략도 사람이 바꿔야 한다.
- 무엇이 왜 작동하는지 모르는 채로 돈이 오간다.

이 시스템이 다르게 접근하는 방식:
- AI가 시장 데이터를 분석하고, 어떤 종목이 왜 유망한지 이유를 남긴다.
- 전략은 AI가 제안하고, 사람이 승인한 것만 실험에 투입된다.
- 실험 결과를 AI가 회고하고, 나빠진 전략은 자동으로 개선 제안이 생성된다.
- 검증된 전략만 실전 배치 후보가 된다.

---

## 3. 전체 흐름

```
[데이터 수집 레이어]
뉴스 · 공시(DART/EDGAR) · 수급(외국인/기관) · 가격/거래량
미국장 지수 · 금리 · VIX · 매크로 지표 · 테마/섹터 데이터

       ↓ AI가 선별·구조화

[시장 지능 레이어]
후보 종목 발견 → 맥락(왜 유망한가) 보존
스캐너 자동 생성/수정 제안
시장 체제(레짐) 분류 (risk_on / neutral / risk_off)

       ↓ 자동 배정

[실험 레이어 — Paper 영역]
스캐너 → 후보 종목 → 전략 자동 배정
전략 버전별 성과 비교 실험
AI가 분석 · 개선 제안 생성
사람이 승인 → 새 버전(DRAFT) 생성
회고: 제안이 실제로 개선됐는지 추적

       ↓ 사람 승인 게이트

[실전 배치 레이어 — 사람 영역]
승격 기준 자동 평가 → 후보 목록 제시
사람이 최종 승인 → 실전 자동매매 활성화
실전 성과 모니터링 + 알림
```

## 4. 핵심 원칙

### 원칙 1: AI는 연구·분석·제안 담당, 사람은 실전 배치 승인 담당

- AI는 데이터를 수집하고, 후보를 발견하고, 전략을 제안하고, 회고한다.
- AI는 절대로 실전 자동매매를 켜지 않는다.
- AI 제안은 항상 `pending` 상태 → 사람이 승인해도 항상 `DRAFT + auto_trade=False`.
- 실전 활성화(`ACTIVE + auto_trade=True`)는 사람이 직접 한다.

### 원칙 2: Paper 영역은 최대한 자동화

- 데이터 수집, 스캔, 후보 발견, 전략 배정, 실험, AI 분석, 제안 생성 → 자동
- 사람의 개입 없이 24시간 연구 루프가 돌 수 있어야 한다.
- 스케줄러 잡이 연구 루프를 구동한다 (기본 비활성, 사람이 켜는 방식 유지).

### 원칙 3: 전략은 수정이 아니라 버전 비교

- 기존 전략 버전은 덮어쓰지 않는다.
- 개선은 항상 새 버전으로 생성 → 구버전과 신버전을 나란히 실험해 비교한다.
- "더 나아졌는가?"를 데이터로 확인하기 전까지는 구버전을 폐기하지 않는다.

### 원칙 4: 맥락과 이유를 보존한다

- "왜 이 종목이 후보가 됐는가?" → `matched_conditions`, `facts` 보존
- "왜 AI가 이 파라미터를 제안했는가?" → `reasoning` 보존
- "왜 이 제안이 좋았거나 나빴는가?" → 회고 결과 보존
- 맥락 없는 숫자는 학습이 안 된다.

### 원칙 5: 멀티마켓 (한국 + 미국)

- 한국장과 미국장을 각각 독립적으로, 또는 맥락으로 연결해 분석한다.
- 미국 전일 지수/금리/VIX → 다음 날 한국장 맥락에 반영.
- 전략과 스캐너는 `market=KR` / `market=US` 로 분리.

## 5. 완전 자동화 목표

최종적으로 이런 시스템을 만드는 것이 목표다:

| 영역 | 자동화 수준 | 사람 역할 |
|------|------------|-----------|
| 데이터 수집 | 완전 자동 | 수집기 추가/비활성화 승인 |
| 시장 분석·후보 발견 | 완전 자동 | 결과 검토 (선택) |
| 전략 실험 (Paper) | 완전 자동 | 결과 검토 (선택) |
| AI 제안 생성 | 완전 자동 | 제안 승인/거절 |
| 실전 배치 | **사람 승인 필수** | 최종 승인 (거부권 보유) |
| 리스크 관리 | 자동 (6가지 룰) | 한도 설정 |
| 긴급 정지 | 자동 (EmergencyStop 룰) | 사전 임계값 설정 |
