# C-7 — 전략 합성 파이프라인 (최종 목표 로드맵)

> 작성: 2026-07-04
> 최종 목표: **"AI가 웹의 유명 매매 전략을 가져와 → 코드로 변환 → 모의투자 검증 →
> 기록을 종합해 알맞은 전략 선정 → (사람 승인 하에) 실전 적용"**
> 기존 검증 체인(백테스트→제안→승인→paper→회고→승격)은 완성돼 있다 — 빠진 것은
> **전략의 입구(수집·변환)와 출구(종합 선정 기준)**다.

---

## 아키텍처

```
[C-7.2/7.3 전략 지식]           [C-7.1 변환·실행]              [기존 검증 체인]
유명 전략 카탈로그(시드)   →   전략 DSL (JSON 스펙)      →   자동 백테스트 (C-6.1)
LLM 전략 리서처(신규 발굴)     rule_based 룰 엔진 해석        → pending 제안 (+백테스트 첨부)
  출처·근거 보존                — 임의 코드 실행 없음          → 사람 승인 → paper TESTING
                                                              → 실험·회고 (C-2.27/2.46)
[C-7.4 선정]                                                  → 승격 게이트 (C-2.29, 사람)
종합 스코어 = 백테스트 + paper 성과 + 회고 + MDD + 레짐 적합성(D-31)
```

## 핵심 설계 결정

1. **DSL over 코드 생성**: LLM은 Python이 아니라 선언적 JSON 스펙을 생성한다.
   - 안전 (임의 코드 실행 없음), 스키마 검증 가능, 백테스트로 즉시 실증 가능
   - 표현력 한계는 지표·연산자 어휘 확장으로 해소 (v1 어휘로 유명 전략 대부분 표현 가능)
2. **검증 없이는 어떤 전략도 배치되지 않는다**: DSL 스키마 검증 → 백테스트 통과 기준
   (§C-7.5) → pending 제안 → 사람 승인 → paper → 회고. 실전은 승격 게이트(사람).
3. **출처 보존**: 전략마다 출처(문헌/유명 트레이더/LLM 리서치)와 원리 설명을 스펙에 동봉.

## C-7.1 — Strategy DSL + 룰 엔진 `DONE`
- `rule_based` 전략 타입: parameters.rule_spec = {indicators, entry(조건 AST), exit(조건 AST)}
- 조건 AST: 비교(gt/lt/…), 교차(crosses_above/below), and/or, 지표 참조, 상수, 가격 참조
- 지표 어휘 v1: sma/ema/rsi/macd(기존) + bollinger/atr/highest/lowest/stochastic/return_pct(신규)
- 백테스트·러너·제안 파이프라인에서 기존 전략과 동일하게 동작 (registry 등록만으로)

## C-7.2 — 유명 전략 카탈로그 시드 `DONE`
- 검증된 고전 전략을 DSL로 시드: 볼린저 하단 반등, 터틀(돈치안 20/10 — breakout_high의 DSL판),
  골든크로스+거래량, 스토캐스틱 과매도, 변동성 돌파(래리 윌리엄스), 듀얼 모멘텀(단순화) 등
- `POST /strategy-catalog/seed` — 시드 시 자동 백테스트 → 기준 통과분만 pending 제안 생성
- 출처·원리 설명 동봉

## C-7.3 — LLM 전략 리서처 `DONE` (수동 트리거 API, 잡 없음)
- LLM(기존 provider 패턴)에게 "유명/검증된 매매 전략을 DSL 스펙으로 제안하라" 프롬프트
  → JSON 파싱 → 스키마 검증 → 자동 백테스트 → 통과 시 pending 제안
- 잡 기본 off (LLM 비용). 중복 방지: 기존 카탈로그와 스펙 해시 비교
- 웹 검색 연동은 후속 (v1은 LLM 지식 기반 — 유명 전략은 LLM이 이미 안다)

## C-7.4 — 종합 선정 스코어 `READY`
- `GET /strategy-selection-board`: 버전별 종합 점수
  = 백테스트(수익·MDD) × paper 실적(기대값·표본) × 회고 판정 × 레짐 적합성 태그
- D-31 반영: 전략에 적합 레짐 태그(trend/range) — 현재 레짐과 매칭 가중
- 승격 게이트 화면에 랭킹 노출 (실전 ON은 여전히 사람)

## C-7.5 — 자동 검증 통과 기준 (전략 입학 시험)
| 기준 | 임계 |
|---|---|
| 백테스트 기간 | 1년 (일봉) 또는 가용 전체 |
| 거래 수 | ≥ 5 (표본) |
| 수익률 | > 0 그리고 MDD < 35% |
| 대조 | 단순보유 대비 MDD 개선 또는 수익 우위 중 하나 |
| paper 승격 | 기존 promotion_criteria + 회고 improved |
- 기준 미달 스펙은 제안조차 만들지 않고 기록만 남긴다 (백테스트 run은 보존 — 학습 재료)

## 하지 말 것
- LLM 생성 Python 실행 금지 (DSL만)
- 검증 없는 전략 배치 금지, 승인 없는 실전 금지 (불변식)
- 카탈로그 시드가 기존 버전을 덮어쓰지 않는다 (항상 신규)
