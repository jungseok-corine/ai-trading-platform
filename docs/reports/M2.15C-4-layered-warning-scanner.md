## 1. Executive summary

대형 52주 range/gain을 **비차단 `strategy_extreme` 경고**로 강등하고, **분할 의심(일일점프>50%)만 운영 차단**으로
유지. 결과: dev DB 5종 read-only 재스캔에서 **000660·005930가 운영 `B`(safe=True, is_strategy_extreme=True,
adj_suspect=False)** 로 노출, 035420/005380/051910은 `none`(safe=True). hard 결함은 여전히 `invalid_data`. 전체
백엔드 **1784 passed**(+16). DB/안전 불변식 무변경. DECISIONS **D-28** 기록.

## 3. Policy implemented (D-28)

- **hard_errors** → `invalid_data`(연구·운영 모두 분류 불가): nonpositive·high<low·close 범위밖·null/파싱불가·중복일.
- **adjustment_warnings**(일일 종가 점프 >50%) → **운영 차단**: 후보면 `*_raw_needs_adjusted_review`,
  `operationally_safe=False`.
- **strategy_extreme_warnings**(`range_ratio>4`·`gain>500%`) → **비차단**: `is_strategy_extreme=True`만, 운영 분류
  막지 않음(Candidate B는 본래 큰 gain을 노린다).
- `operationally_safe = is_data_valid AND ready_for_52w AND not is_adjustment_suspect`(전략-극단 무관).

## 5. Classification rules

- **연구 bucket**: `invalid_data`(hard) / `insufficient_data`(<252) / `A` / `B` / `none` — **경고 무관**.
- **운영 bucket**: `invalid_data` / `insufficient_data` / 조정의심+A→`A_raw_needs_adjusted_review` /
  조정의심+B→`B_raw_needs_adjusted_review` / 조정의심+무후보→`none` / 깨끗 A→`A` / 깨끗 B→`B` / else `none`.
- 정렬은 운영 bucket 우선순위(A<B<A_review<B_review<none<insufficient<invalid)→drawdown asc→gain desc→symbol.
