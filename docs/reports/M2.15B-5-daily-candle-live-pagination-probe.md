## 11. Adjusted / raw behavior

- 추세 분석엔 수정주가(`adjusted=True`, `=1`) 권장 — 채택 여부는 execute-pilot(M2.15B-6) 설계에서 확정.

## 12. Rate-limit observation

- 1회 `EGW00201`("초당 거래건수를 초과하였습니다") 관측 → `_request`의 내장 backoff/retry(attempt 1/3)가
  **자동 재시도하여 복구**, 최종 성공. 별도 데이터 손실/실패 없음.
- 252봉×다종목 수집(M2.15B-6) 시 호출량 증가 → collector의 동시성 1·간격 정책 + 기존 EGW00201 backoff 유지 필요.

## 15. Conclusion

- **페이지네이션 라이브 검증 성공** — 005930에서 252봉 read-only 수집이 실제로 가능함을 확인(3 페이지, dedupe 0,
  최신일 우선, OHLCV/volume/trading_value 완전). **52주 지표 부트스트랩에 충분.**
- 다음 후보: **M2.15B-6 execute-pilot(별도 승인) — 우선 1종목 → 이후 1~5종목**, 라이브 read-only 수집 결과를
  `market_data timeframe="1d"`에 멱등 적재. 수정주가(`adjusted=True`) 채택 여부, trading_value 컬럼 추가 여부는
  M2.15B-6 설계에서 결정(컬럼은 별도 승인 마이그레이션).
- M2.15B-5a(페이지네이션/엔드포인트 수정)는 **불필요** — 실패 없음.

## 16. execute-pilot 미승인 명시

**execute-pilot은 여전히 미승인이다.** 본 작업은 라이브 read-only 검증만 수행했으며, DB 적재(execute-pilot)는
별도 명시 승인이 있어야 진행한다. M2.14B-3d(무인 디스패처)도 별개이며 미승인 상태 유지.
