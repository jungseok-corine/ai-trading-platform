## 1. Executive summary

**저장 52주 이력이 KIS 실전 도메인 일봉과 정합**: 5종 모두 **52주 저점 정확 일치**(57,600 / 242,000 / 190,300 /
200,500 / 200,500), 52주 고점 ≤1.5% 차, 현재가 ≤0.7% 차. 레퍼런스로 재계산한 gain/dd가 **운영 B를 재현**(005930
460.76%, 000660 985.95%). → D-2(현재가)에 더해 **B 분류의 핵심 드라이버인 52주 이력까지 실전 도메인으로 검증** —
000660·005930 B는 paper-only 아티팩트가 아니다. **단 잔존 한계**: D-2에서 확인됐듯 KIS 실전·모의 도메인이 동일
시세를 반환하므로 이는 **KIS 생태계 내 정합성**이며, KIS 외 독립 소스(미설치)로 실세계 정확성을 확증한 것은
아니다. → **권고: Option B(강화) — research-only 노출 + 출처 경고**(52주 이력 검증됨, 단 비-KIS 독립성은 미확보).
DB/안전 불변식 무변경.

## 3. Historical reference source feasibility

1. `KISRealBrokerClient`에 **일봉 메서드 없음**(get_current_price·get_minute_candles만 quotation; get_daily_executions는
   체결이력=trading). → 일봉 wrapper 부재.
2. 그러나 일봉 **시세 엔드포인트**(`inquire-daily-itemchartprice`, FHKST03010100)는 quotation이라 실전 도메인에서
   read-only 호출 가능(상속 `_request`로, 런타임 코드 변경 없이 /tmp에서).
3. `KIS_REAL_TRADING_ENABLED=false`로 호출 가능(quotation은 거래 플래그 무관).
4. quotation 엔드포인트(주문 아님). 5. TR=FHKST03010100. 6. place_order 봉쇄/미호출. 7. DB write/영속화 위험 없음
   (메모리 계산만). 8. 실전 키 configured. 9. 토큰 캐시 gitignored. 10. 비-KIS 패키지(pykrx/yfinance 등) 미설치.

→ **안전 read-only 실전 일봉 레퍼런스 가용** → 사용.

## 10. 000660 / 005930 realism assessment

- **검증 강화**: D-2(현재가 일치)에 더해 **52주 high/low/gain/drawdown이 실전 도메인 일봉과 정합**(저점 정확 일치,
  고점 ≤1.5%) → B 분류의 52주 드라이버가 실전 도메인에서 재현됨. **paper-only 아티팩트 아님**(현재가·이력 모두).
- **잔존 한계(정직)**: KIS 실전·모의 도메인이 **동일 시세**를 반환(D-2 확인)하므로, 본 검증은 **KIS 생태계 내부
  정합성**이다. KIS 외 독립 소스(pykrx/yfinance 미설치, 모델 cutoff 2026-01 < sim 2026-06-29)가 없어 **실세계
  가격 정확성·도메인 독립성은 여전히 미확증**. 000660 1년 ~10배는 역사적으로 극단이나 KIS 양 도메인이 일관 보고.
- 결론: **현재가·52주 이력 모두 KIS 실전 도메인으로 검증 · 비-KIS 독립성만 미확보.**

## 11. Recommendation → **Option B (강화: research-only + 출처 경고)**

- **Option C(차단) 기각**: 52주 이력이 실전 도메인 일봉과 정합(저점 정확 일치) — 중대 괴리 없음.
- **Option A(클린 노출) 미채택**: 검증이 전부 **KIS 생태계 내부**(실전·모의 동일 데이터) — 비-KIS 독립 확증 부재.
- **Option B 권고(강화)**: research-only 노출 허용. 단 **데이터 출처 경고** 필수("현재가·52주 이력 모두 KIS 시세와
  정합하나 검증은 KIS 생태계 내부 — 비-KIS 독립 소스 없음; 개발/연구 뷰; 매수 신호 아님"). is_strategy_extreme/
  경고 라벨 유지. → M2.15D-3B(research-only 노출)로 진행 가능 수준.
- **Option D(소스 부재) 부분 해당**: 완전 독립 검증을 원하면 비-KIS 소스 통합이 별도 선행(선택적).
