## 4. Response fields

- 메타: `scanned_at` · `universe_scope`(pilot_5/explicit) · `research_only=true` · `not_buy_signal=true` ·
  `provenance_warning` · `safety_warning` · `total_symbols_scanned` · `total_operational_candidates`.
- `candidates`(operational bucket ∈ {A,B}) + `results`(전체). 각 항목: symbol · candidate_bucket_research ·
  candidate_bucket_operational · candidate_bucket(별칭) · operationally_safe_for_classification · is_strategy_extreme ·
  is_adjustment_suspect · is_data_valid · hard_errors · adjustment_warnings · strategy_extreme_warnings ·
  data_quality_warnings · current_close · high_52w · low_52w · low_52w_gain_pct · drawdown_from_52w_high_pct ·
  ma20 · ma50 · recent_20d_high · volume_20d_avg · daily_count · oldest_date · newest_date · ready_for_52w ·
  raw_candidate_a · raw_candidate_b.
- **"signal"/"recommendation"/"buy"/"order"/"trade"를 긍정 라벨로 쓰지 않음** — 경고 문구에서만 "NOT buy signals".
