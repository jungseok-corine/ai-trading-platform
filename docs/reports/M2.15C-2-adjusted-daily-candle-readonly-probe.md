# M2.15C-2 — Adjusted Daily Candle Read-Only Probe / Price Policy Decision

> 5종 파일럿에 대해 **adjusted=True(`FID_ORG_ADJ_PRC=1`) 라이브 read-only 프로브** + 동일 메트릭 인메모리 계산 +
> raw(저장값) 대조. **adjusted 봉 미적재 · raw 봉 미덮어쓰기 · DB write 0 · 마이그레이션 없음 · 후보 영속화 없음 ·
> SignalLog/Trade/Order 0 · KIS 주문/place_order 0 · 스케줄러/디스패처 0 · 시크릿 미출력 · M2.14B-3d 미승인.**
> **후보는 매수 신호가 아니다.**

---

## 1. Executive summary

**adjusted=True는 경고를 해소하지 못했다.** 5종 모두 adjusted 메트릭이 raw와 **사실상 동일**(특히 **high_52w·
low_52w가 raw와 정확히 일치**). 000660·005930는 adjusted에서도 `B_raw_needs_adjusted_review`(safe=False) 유지,
나머지 3종은 none(safe). 즉 **대형 52주 range/gain은 raw-vs-adjusted 아티팩트가 아니라 데이터 자체의 실제
특성**이다(추가 확인: 저가 구간은 단일 이상치가 아니라 2025-06~ 다일 연속). → **Option B**: raw 유지 + 스캐너의
운영 분류 차단 유지. 단, 경고 임계값이 **실제 강한 주도주**를 데이터 의심으로 오분류하는 측면이 있어, 다음은
저장/마이그레이션이 아니라 **임계값/전략의도·데이터 현실성 재검토(M2.15C-3)**. DB/안전 불변식 무변경.

## 9. Data-quality warning comparison & 추가 진단

- 경고 임계값(range>4 / gain>500% / 일일점프>50%) 발화는 raw·adjusted 동일.
- **추가 read-only 진단**: 저가 구간은 단일 이상치가 아님 — 005930 최저가(~57,600)는 2025-06-18/23/24 등 **다일
  연속**(중앙값 close 110,100, 현재 ~323,000), 000660 최저(~242,000)도 2025-06~08 다일(중앙값 604,000, 현재
  ~2,610,000). → 대형 range/gain은 **데이터 내 실제 1년 상승추세**이며, 단일 결손/조정 봉이 아니다.

## 13. Price-adjustment policy recommendation → **Option B (+ 후속 재검토)**

- **Option A(수정주가 채택) 기각**: adjusted=True가 경고를 해소하지 못함(high_52w/low_52w raw=adjusted 동일).
  수정주가 도입의 실익 없음.
- **Option B 채택**: **raw 유지 + 스캐너 운영 분류 차단 유지**. 현재 데이터로 운영 후보 0개가 정상(보수적 가드).
- 단, 경고 임계값이 **실제 강한 주도주(연속 상승)** 를 "데이터 의심"으로 묶는 한계가 드러남 →
  raw-vs-adjusted 문제가 아니라 **임계값/전략의도·데이터 현실성** 문제. 이는 **M2.15C-3(별도)** 에서 다룬다.

## 14. Storage / schema implications

- 현재 `market_data`는 raw/adjusted를 구분할 컬럼/키가 없다(`adjustment_mode` 없음, `(symbol,timeframe,ts)` 단일
  키). **adjusted가 raw와 수치상 동일하므로 별도 저장(예 `1d_adj` timeframe)·`adjustment_mode` 컬럼 추가의 실익이
  지금은 없다.** raw와 adjusted를 같은 키에 혼재시키지 않는다.
- 향후 수정주가가 실제로 달라지는 종목/기간을 다루게 되면, (1) `adjustment_mode` 컬럼+유니크 확장, 또는
  (2) `1d_adj` 별도 timeframe, 또는 (3) raw 저장+adjusted는 read-only 라이브 계산만 — 의 트레이드오프를 별도 승인
  마이그레이션/설계로 결정한다. **본 작업에서 어느 것도 구현하지 않는다.**
