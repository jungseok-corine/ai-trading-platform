## 1. Executive summary

**저장 일봉의 현재가 스케일은 KIS 실전 도메인 시세와 ≤0.7%로 일치**(5종 전부 `matches_reference`). 즉 D-1에서
제기한 "비현실적 가격" 우려는 **현재가 수준에 한해 실전 레퍼런스로 확인됨** — 005930·000660의 운영 B는 paper-only
아티팩트가 아니다. **단 한계**: ① 비교한 것은 **현재가뿐**(실전 `get_current_price`는 당일 시세 — B 분류를 만드는
**52주 저점/이력은 미검증**); ② **KIS 외 독립 소스 부재**(pykrx/yfinance 등 미설치) — 실전 도메인이 진짜 production인지
dev/mock과 같은 데이터를 공유하는지 독립 확인 불가; ③ 모델 지식 cutoff(2026-01)가 sim 일자(2026-06-29)보다 과거.
→ **권고: Option B — research-only 노출 + 강한 데이터 출처 경고**(현재가 스케일은 검증, 52주 이력·독립성은 미검증).

## 10. 000660 / 005930 realism assessment

- **개선**: 두 종목의 **현재가가 실전 도메인 시세와 일치**(005930 323,000=323,000; 000660 2,610,000 vs 2,628,000,
  -0.7%) → 운영 B는 paper-only 아티팩트가 아니다. D-1의 스케일 우려는 현재가 한정으로 **완화**.
- **남은 의문**: ① 52주 이력(005930 저점 57,600 → gain 460%)은 **실측 미검증**; ② KIS 외 독립 소스가 없어 실전
  도메인이 진짜 production인지(또는 paper와 동일 dev 데이터 공유) **독립 확인 불가**; 두 도메인이 동일값을 반환한다는
  점은 정합성이지만 독립성 증거는 아니다. ③ 980% 1년 상승(000660)은 역사적으로 극단 — 실측 일봉 검증 권장.
- 결론: **현재가 스케일 OK · 52주 이력/독립성 미검증** → research-only 적합, 운영 배치엔 추가 검증 필요.

## 11. Recommendation → **Option B (research-only + 출처 경고)**

- **Option C(차단) 기각**: 현재가가 실전 레퍼런스와 일치 → 데이터 중대 괴리 없음.
- **Option A(클린 노출) 미채택**: 52주 이력 독립 미검증 + KIS 외 소스 부재 → "현재가만 검증"으로 클린 단정 불가.
- **Option B 권고**: research-only 노출 허용하되 **강한 데이터 출처 경고**("현재가는 KIS 시세와 일치하나 52주 이력은
  독립 미검증; 개발/연구 뷰; 매수 신호 아님") 필수. is_strategy_extreme/경고 라벨 유지.
- **Option D 일부 해당**: 진짜 독립 실측 소스(외부)는 환경에 없음 → 더 강한 검증을 원하면 소스 통합이 별도 선행.
