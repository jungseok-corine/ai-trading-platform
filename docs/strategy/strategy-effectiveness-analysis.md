## 6. 하락 구간 분리 검증 (2026-07-03 저녁 추가) — 결론 수정

§3의 "breakout 최강" 결론은 **강세장 한정**이었다. 하락·횡보 검증 결과:

| 구간 | breakout(20/10) | rsi_reversion(40) |
|---|---|---|
| NAVER 1년 (횡보~하락, 보유 +0.5%) | **-42.7% / MDD 45%** 💀 | +1.8% / MDD 31% |
| 최근 3개월 하락 종목들 | 시장보다 더 잃음 (-18%, -13%) | NAVER **+34%** (반등 포착), 평균 MDD 9.6% |
| 최근 3개월 강세 종목 | 보유 대비 언더퍼폼이나 수익 | 005930 -10% (기회비용) |

**수정된 결론: 만능 전략은 없다 — 조건부 조합이 답이다.**
- breakout = 추세 종목/강세 국면 전용. 횡보 종목에선 허위 돌파 연쇄로 재앙적
- rsi_reversion = 횡보·하락 반등 전용. MDD 방어 우수, 추세장에선 기회비용
- **이것이 정확히 매크로 레짐(C-2.49) + 변동성 밴드(C-6.4) 인프라의 존재 이유**:
  risk_on/추세 → breakout 가동, risk_off/횡보 → rsi 가동 (또는 종목별 특성 매칭)

### 후속 과제
- **종목-전략 적합성 매칭**: 추세성 지표(예: 최근 60일 방향성)로 종목을 분류해
  breakout↔rsi를 자동 배정 — 기존 assignment 시스템의 자연스러운 확장
- v334(breakout·005930)는 적합(추세 종목), v335(rsi·005930)는 부적합 가능성 —
  paper 신호로 검증 후 rsi는 NAVER류 횡보 종목으로 재배정 검토
