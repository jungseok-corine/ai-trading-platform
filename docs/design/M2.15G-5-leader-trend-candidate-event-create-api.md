# M2.15G-5 — Manual LeaderTrendCandidateEvent Create API

> **explicit manual create API 1개만.** read/list/update/delete/bulk/save-all API 0 · auto-save 0 · 스케줄러 0 ·
> trading 미연결 · dev/prod migration 적용 0 · 운영 record 생성 0 · 외부/KIS 0 · frontend 0.
> DB write 검증은 **테스트 DB의 `leader_trend_candidate_events` insert만**. **record는 매수 신호가 아니다.**

## 1. Endpoint

`POST /api/v1/leader-trend/candidate-events/research-only` — status 201.
**service(`LeaderTrendCandidateEventService.create_research_event`)를 통해서만** 생성. route는 service만 호출하고
직접 DB insert/KIS/market fetch/scanner/AI를 하지 않는다. service가 create policy의 source of truth.

금지 endpoint(미구현): `POST /candidate-events`, `/candidate-events/bulk`, `/candidate-events/save-all`,
`GET /candidate-events`, `GET /candidate-events/{id}`, `PUT/PATCH/DELETE`, automatic save, save+analyze/trade/notify.

## 2. Request schema

`LeaderTrendCandidateEventCreateRequest`: symbol · detected_at · reference_date · timeframe · universe_scope ·
scanner_name · scanner_version · candidate_bucket · is_operational_candidate · strategy_extreme · current_price ·
low_52w · high_52w · low_52w_gain_pct · drawdown_from_52w_high_pct · window_basis · data_source · validation_source ·
validation_status · validation_report_path · research_only · not_buy_signal · (옵션) source_basis_note · notes ·
provenance_warning · safety_warning. → service input으로 매핑(최종 정책 판단은 service).

## 3. Response schema

`LeaderTrendCandidateEventCreateResponse`: id · symbol · reference_date · candidate_bucket · validation_status ·
`research_only=true` · `not_buy_signal=true` · `safety_warning` · `not_buy_signal_warning` · created_at.

- `safety_warning` = "This event is a research-only observation. It must not be connected to trading, orders,
  signals, or recommendations."
- `not_buy_signal_warning` = "This is not a buy signal, sell signal, or investment recommendation."

## 4. Error mapping

- `LeaderTrendCandidateEventValidationError` → **400**
- `LeaderTrendCandidateEventDuplicateError` → **409**

테스트 케이스: unresolved_major_diff/not_validated/explained_major_diff(no note)/research_only false/
not_buy_signal false/missing validation_report_path/non-pilot_5/wildcard/wrong scanner_name/wrong data_source/
wrong timeframe → 400 · duplicate unique key → 409 · success(matched/minor_diff/explained_major_diff+note) → 201.

## 5. No runtime use until migration approval

- 본 API는 코드에 존재하나, **dev/prod DB에는 `leader_trend_candidate_events` 테이블이 아직 없다**(migration 미적용).
  → 실제 운영 호출은 사람의 명시 승인 + `alembic upgrade head`(dev/prod) 이후에만 가능. 현재는 **테스트 DB에서만**
  create 검증.
- 본 API는 **수동 명시 호출용**이며 자동 후보 저장이 아니다. 매수/추천/주문과 연결되지 않는다.
