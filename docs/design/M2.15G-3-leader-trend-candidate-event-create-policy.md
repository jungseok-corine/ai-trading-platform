# M2.15G-3 LeaderTrendCandidateEvent Create Policy Design

> **설계 문서만.** repository/service/API/schema 구현 0 · record 생성 0 · DB insert/update/delete 0 ·
> alembic upgrade 실행 0 · dev/prod migration 적용 0 · 외부/KIS 0 · SignalLog/Trade/Order 0 · 스케줄러 0 · frontend 0.
> **LeaderTrendCandidateEvent record는 매수 신호가 아니다.**

> 공식 이름: model `LeaderTrendCandidateEvent` / table `leader_trend_candidate_events`. (기존
> `CandidateEvent/candidate_events`는 C-2.24 스캐너 룰 도메인 — 별개.)

## 1. Purpose

`LeaderTrendCandidateEvent`는 research-only leader trend 후보가 **특정 기준일에 관찰되었다는 사실**을 저장하는
연구 기록이다. 목적: 후보 발생 이력 축적 · 후보 이후 성과 추적 준비 · bucket A/B/none과 이후 수익률 비교 ·
AI 분석용 ground truth · 실거래/주문/추천과 분리된 리서치 데이터셋.

## 2. Non-goals (명확히 금지)

매수/매도 신호 저장 · 주문 생성 · Trade 생성 · SignalLog 생성 · StrategyRunner 연결 · scheduler 자동 저장 ·
full-universe 자동 확장 · AI 자동 평가 실행 · push notification · 자동 추천 · 실거래 준비.

## 3. Preconditions Before Implementation (M2.15G-4 전)

- dev DB에 `r1s2t3u4v5w6` migration 적용 여부를 **사람 승인**으로 결정.
- `leader_trend_candidate_events` table 존재 확인.
- 기존 `candidate_events`와 역할 구분 확인.
- validation report 존재: `docs/data-validation/non-kis-52w-validation-report-2026-06-29-naver.md`.
- 52w window basis audit 존재: `docs/data-validation/52w-window-basis-audit-2026-06-29.md`.
- unresolved major_diff 없음 · explained_major_diff는 `source_basis_note` 필수 · 여전히 not buy signal.

## 4. Allowed Create Source

초기 create source는 **하나만**: 기존 local `GET /api/v1/leader-trend/candidates` 결과의 research candidate.

금지 source: 외부 API 직접 입력 · KIS live fetch 결과 직접 저장 · AI가 생성한 후보 · 사용자가 임의로 만든
symbol/price · scheduler 자동 결과 · Trade/Order/SignalLog 역생성 · full-universe scan 결과.

## 5. Create Policy

초기 저장은 **explicit manual create만**.

**허용 조건**: `research_only==true` · `not_buy_signal==true` · `data_source==local_market_data` ·
`scanner_name==leader_trend` · `scanner_version` 명시 · `window_basis` 명시 · `validation_source` 명시 ·
`validation_status ∈ {matched, minor_diff, explained_major_diff}` · `explained_major_diff`이면 `source_basis_note`
필수 · `validation_report_path` 필수 · `candidate_bucket ∈ {A,B,none}` · `reference_date`=DB snapshot 기준일 ·
`timeframe==1d` · `universe_scope==pilot_5` · unique key 중복 없음.

**거부 조건**: `research_only!=true` · `not_buy_signal!=true` · `validation_status==unresolved_major_diff` ·
`validation_status==not_validated` · `validation_report_path` 없음 · `source_basis_note` 없이 explained_major_diff ·
`window_basis` 누락 · `scanner_version` 누락 · unique key 중복 · universe_scope!=pilot_5 · full/universe/all/wildcard ·
실시간 현재가 기반 reference · KIS source 직접 사용 · Order/Trade/SignalLog 연결 시도.

## 6. Idempotency / Duplicate Policy

중복 기준: `(symbol, scanner_name, scanner_version, reference_date, timeframe, window_basis, universe_scope)`
(= DB unique key). 정책: **upsert 금지** · 중복이면 409 conflict 또는 domain duplicate error · 기존 record 미변경 ·
최초 구현에서 update endpoint 금지 · delete endpoint 금지.

## 7. Repository Design Proposal (최소 기능)

허용 메서드 후보: `create_research_event(...)` · `get_by_id(...)` · `list_by_reference_date(...)` ·
`exists_by_unique_key(...)`.
금지: bulk create · upsert · update · delete · create from scheduler/strategy runner/AI output/order/trade/signal.

## 8. Service Design Proposal

책임: create input validation · unique key 중복 확인 · validation_status policy 적용 · research_only/not_buy_signal
강제 · explained_major_diff의 source_basis_note 필수 검사 · no trading side-effect 보장.
금지: market data fetch · KIS fetch · candidate scan 실행 · AI 분석 실행 · order/trade/signal 생성 · scheduler 등록 ·
DB migration 실행.

## 9. API Design Proposal (초기 1개)

`POST /api/v1/leader-trend/candidate-events/research-only` (explicit).
필수 body: symbol · reference_date · timeframe · universe_scope · scanner_name · scanner_version · candidate_bucket ·
current_price · low_52w · high_52w · low_52w_gain_pct · drawdown_from_52w_high_pct · window_basis · validation_source ·
validation_status · validation_report_path · source_basis_note · research_only · not_buy_signal.
response: created event id · research_only · not_buy_signal · safety_warning · not_buy_signal_warning.
금지 API: automatic save · bulk save · save all candidates · save+outcome tracking · save+AI analyze · save+notify ·
save+trade.

## 10. Read API Proposal (별도 단계)

`GET /api/v1/leader-trend/candidate-events` · `GET /api/v1/leader-trend/candidate-events/{id}`.
filter 후보: symbol · reference_date · candidate_bucket · validation_status · window_basis. **read API도 not-buy-signal
warning 포함.**

## 11. Testing Plan (M2.15G-4 구현 시)

create success(minor_diff) · create success(explained_major_diff + source_basis_note) · reject(unresolved_major_diff) ·
reject(not_validated) · reject(research_only false) · reject(not_buy_signal false) · reject(missing
validation_report_path) · reject(explained_major_diff without source_basis_note) · reject(duplicate unique key) ·
reject(non-pilot_5 universe) · reject(wildcard/all/full universe) · assert no Order/Trade/SignalLog · assert no
KIS/broker/http · assert scheduler untouched · assert no StrategyRunnerService touch · assert DB write only to
`leader_trend_candidate_events` · full backend pass.

## 12. Implementation Breakdown

- **M2.15G-4**: repository + service only, no API
- **M2.15G-5**: explicit create API
- **M2.15G-6**: read/list API
- **M2.15G-7**: manual create from current leader-trend candidate result
- **M2.15H-1**: candidate outcome tracking design

## 13. Final Decision

- **SAFE TO IMPLEMENT REPOSITORY/SERVICE NEXT: yes**
- **SAFE TO ADD CREATE API NOW: no**
- **SAFE TO CREATE RECORDS NOW: no**
- **SAFE TO CONNECT TO TRADING: no**
- **SAFE TO ENABLE SCHEDULER: no**
- **SAFE TO APPLY DEV/PROD MIGRATION WITHOUT HUMAN APPROVAL: no**
- reason:
  - model/migration exist but **dev/prod DB not yet migrated**.
  - create policy must be implemented in a separate repository/service step (M2.15G-4).
  - event remains **research-only and not a buy signal** — 주문/Trade/SignalLog/스케줄러 미연결.

## 14. M2.15G-4 Implementation Note (repository + service only)

- **구현됨**: `LeaderTrendCandidateEventRepository`(create/get_by_id/list_by_reference_date/exists_by_unique_key) +
  `LeaderTrendCandidateEventService.create_research_event`(create policy 강제) +
  `LeaderTrendCandidateEventCreateInput`(service-local). (→ `docs/design/M2.15G-4-leader-trend-candidate-event-service.md`.)
- **여전히 차단**: **API route 미구현**(create/read API는 G-5/G-6) · runtime auto-save 없음 · record는 **테스트 DB에서만**
  생성 검증 · **dev/prod migration 미적용**(사람 승인 필요) · trading/scheduler 미연결.

## 15. M2.15G-5 Implementation Note (manual create API)

- **구현됨**: `POST /api/v1/leader-trend/candidate-events/research-only` (explicit manual create, service 경유).
  (→ `docs/design/M2.15G-5-leader-trend-candidate-event-create-api.md`.) error: validation→400, duplicate→409.
- **여전히 차단**: read/list/update/delete/bulk/save-all API 없음 · auto-save 없음 · trading/scheduler 미연결 ·
  **dev/prod migration 미적용**(테이블 부재 → 실제 운영 호출은 사람 승인 + upgrade 후에만). record는 테스트 DB에서만 검증.
