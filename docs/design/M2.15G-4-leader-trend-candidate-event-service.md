# M2.15G-4 — LeaderTrendCandidateEvent Repository + Service

> **repository + service only.** API route 0 · FastAPI endpoint 0 · frontend 0 · dev/prod migration 적용 0 ·
> runtime auto-save 0 · 외부/KIS 0 · order/trade/signal 0 · 스케줄러 0. DB write는 **테스트 DB의
> `leader_trend_candidate_events` insert 검증에만**. **record는 매수 신호가 아니다.**

## 1. Repository

`app/domain/repositories/leader_trend_candidate_event.py` — `LeaderTrendCandidateEventRepository`.
BaseRepository를 **상속하지 않는다**(generic update/delete 노출 방지). 메서드:
- `create(event) -> LeaderTrendCandidateEvent`
- `get_by_id(id) -> LeaderTrendCandidateEvent | None`
- `list_by_reference_date(reference_date, *, limit, offset) -> list[...]`
- `exists_by_unique_key(*, symbol, scanner_name, scanner_version, reference_date, timeframe, window_basis, universe_scope) -> bool`

**없음**: upsert · bulk_create · update · delete · create_from_scheduler/strategy_runner/ai/trade/order/signal.
순수 DB 접근 — KIS/broker/http/scheduler import 없음 · 기존 `candidate_events`(C-2.24) 미참조.

## 2. Service

`app/services/leader_trend_candidate_event_service.py` — `LeaderTrendCandidateEventService` +
`LeaderTrendCandidateEventCreateInput`(service-local dataclass, **API schema 아님**).

메서드: `create_research_event(input) -> LeaderTrendCandidateEvent` — 정책 검증 → unique key 중복 검사 →
단일 record append. **주문/신호/스케줄러 부작용 없음 · market data/KIS/external fetch 없음.**

## 3. Validation rules (create policy 강제)

허용 status: `matched` · `minor_diff` · `explained_major_diff`(+ `source_basis_note` 필수).
강제: `research_only==true` · `not_buy_signal==true`(DB record는 항상 true로 저장) · `scanner_name=="leader_trend"` ·
`scanner_version` 필수 · `data_source=="local_market_data"` · `timeframe=="1d"` · `universe_scope=="pilot_5"` ·
`candidate_bucket ∈ {A,B,none}` · `window_basis ∈ {last_252_trading_rows, calendar_52_weeks, source_reported}` ·
`validation_report_path` 필수.

거부: `unresolved_major_diff` · `not_validated` · explained_major_diff without source_basis_note ·
research_only/not_buy_signal false · validation_report_path/scanner_version/window_basis 누락 · 잘못된 bucket/
window_basis/status · universe_scope!=pilot_5 · wildcard(all/full/universe/*) · timeframe!=1d · scanner_name!=
leader_trend · data_source!=local_market_data → `LeaderTrendCandidateEventValidationError`.

## 4. Duplicate policy

unique key = `(symbol, scanner_name, scanner_version, reference_date, timeframe, window_basis, universe_scope)`.
중복이면 `LeaderTrendCandidateEventDuplicateError`(저장 안 함). **upsert/update/delete 없음.**

## 5. Explicit no API / no scheduler / no trading

- **API route 추가 안 함**(create/read API는 G-5/G-6). FastAPI endpoint 0.
- scheduler/dispatcher 미연결 · auto-save 없음 · order/trade/signal 생성 없음 · broker/KIS 호출 없음.
- DB write는 `leader_trend_candidate_events` insert만(테스트 DB 검증). **dev/prod migration 미적용**(사람 승인 필요).

## 6. Next phase gate

- **M2.15G-5**: explicit create API. **M2.15G-6**: read/list API. **M2.15G-7**: 현재 candidate 결과에서 manual create.
- dev/prod migration 적용 · record 운영 생성 · trading/scheduler 연결은 여전히 **별도 승인** 필요.
